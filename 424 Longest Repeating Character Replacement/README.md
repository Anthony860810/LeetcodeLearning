# 424. Longest Repeating Character Replacement

## 題目描述

給定一個只包含大寫英文字母的字串 `s` 和整數 `k`，最多可以將 `k` 個字元替換成其他字元。請找出替換後可以形成的最長連續、且內容相同的子字串長度。

## 解題思路：Sliding Window

使用 `left` 和 `right` 建立滑動視窗，並用 `map` 記錄目前視窗內每個字元出現的次數。

設 `max_ch_cnt` 為視窗內出現次數最多的字元數量。若要將整個視窗變成同一個字元，需要替換的字元數為：

```text
視窗長度 - 視窗內最高頻率
```

當這個數量大於 `k` 時，代表目前視窗不合法，就從左側移除字元並將 `left` 向右移動。視窗合法時，更新最長長度。

```cpp
while ((right - left + 1) - max_ch_cnt > k) {
    map[s[left]]--;
    left++;
}
```

## 與初版想法的差異

初版固定 `s[i]` 作為要保留的字元，但最佳答案不一定是以 `s[i]` 為主。例如視窗內其他字元可能出現得更多，因此應該記錄「目前視窗內出現最多次的字元」。

另外，初版的 `next` 可能超出 `s` 的範圍，會造成越界存取；`unordered_set<char> chars` 也沒有實際用於計數。滑動視窗可以在每個字元最多進入與離開一次的情況下完成搜尋。

## 複雜度

- 時間複雜度：`O(N)`
- 額外空間複雜度：`O(1)`，因為字元種類最多只有 26 種
