# 167. Two Sum II - Input Array is Sorted

## 題目描述

給定一個已經按照非遞減順序排列的整數陣列 `numbers`，請找出兩個數字，使它們的總和等於 `target`。

題目保證恰好存在一組答案，且同一個元素不能使用兩次。回傳兩個數字的 **1-based index**。

## Solution 1：雙指標搜尋

使用 `head` 和 `tail` 分別指向陣列的最左側與最右側：

- 如果兩數總和等於 `target`，記錄答案並結束迴圈。
- 如果總和大於 `target`，將 `tail` 左移，讓總和變小。
- 如果總和小於 `target`，將 `head` 右移，讓總和變大。

時間複雜度是 `O(N)`，空間複雜度是 `O(1)`。

## Solution 2：找到答案後直接回傳

想法與 Solution 1 相同，但找到答案後直接回傳 `{front + 1, end + 1}`，不需要額外建立結果陣列，也不需要使用 `break` 結束迴圈。

由於陣列已排序，每次移動一個指標都能排除一部分不可能的組合，因此兩個指標總共最多移動 `N` 次。

時間複雜度：`O(N)`  
空間複雜度：`O(1)`
