# 11. Container With Most Water

## 題目描述

給定一個整數陣列 `heights`，其中 `heights[i]` 代表第 `i` 條垂直線的高度。請找出兩條線，讓它們與 x 軸形成的容器可以裝最多的水。

容器面積計算方式為：

```text
寬度 × 較短的高度
```

## 解題思路：雙指標

使用 `left` 和 `right` 分別指向陣列的最左側與最右側。每次計算目前兩條線形成的面積，並更新最大值。

接著移動高度較短的那一側：

- 如果 `heights[left] > heights[right]`，移動 `right`。
- 否則移動 `left`。

## 為什麼移動較短的一側？

面積的高度由兩條線中較短的那條決定。假設左側較短，若只移動右側，寬度會變小，而新的右側高度即使變高，面積仍然最多受到原本左側較短高度限制，因此不可能得到更大的面積。

只有移動較短的左側，才有機會找到更高的柱子，抵銷寬度縮小造成的損失。

## 複雜度

- 時間複雜度：`O(N)`
- 額外空間複雜度：`O(1)`
