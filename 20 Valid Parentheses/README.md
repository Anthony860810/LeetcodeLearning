# 20. Valid Parentheses

## 題目描述

給定一個只包含 `(`、`)`、`[`、`]`、`{`、`}` 的字串 `s`，判斷括號是否有效。

有效字串必須符合：

- 每個左括號都要有相同類型的右括號配對。
- 括號必須按照正確順序關閉。
- 每個右括號都必須有對應的左括號。

## 解題思路：Stack

括號具有「最後出現的左括號要最先被關閉」的特性，符合 Stack 的 LIFO（Last In, First Out）行為。

掃描字串時：

- 遇到左括號，就放入 stack。
- 遇到右括號，先確認 stack 是否為空。
- 如果 stack 不為空，檢查 stack 頂端是否為相同類型的左括號。
- 配對成功就移除頂端，配對失敗就直接回傳 `false`。

掃描結束後，如果 stack 為空，代表所有左括號都已經成功配對；否則代表仍有未關閉的左括號。

## 重要細節

遇到右括號時，不能直接呼叫 `container.top()`，必須先確認 stack 不為空，否則可能造成未定義行為：

```cpp
if (container.empty()) {
    return false;
}
```

## 複雜度

- 時間複雜度：`O(N)`
- 額外空間複雜度：`O(N)`，最壞情況下所有字元都是左括號
