# 15. 3Sum

## 題目描述

給定一個整數陣列 `nums`，找出所有三個不同位置的元素，使三個數字相加等於 `0`。

回傳的結果不能包含重複的三元組，例如 `[-1, 0, 1]` 只能出現一次。

## 解題思路

先將陣列排序，接著固定第一個數字 `nums[i]`，再使用兩個指標：

- `j` 從 `i + 1` 開始向右移動。
- `k` 從陣列尾端開始向左移動。

比較 `nums[i] + nums[j] + nums[k]`：

- 總和等於 `0`：加入答案，並移動 `j`。
- 總和小於 `0`：需要更大的總和，因此 `j++`。
- 總和大於 `0`：需要更小的總和，因此 `k--`。

因為陣列已排序，所以可以有效判斷指標的移動方向。

## 去除重複

固定第一個數字時，如果 `nums[i] == nums[i - 1]`，就跳過這次迴圈，避免產生重複三元組。

找到一組答案後，將 `j` 向右移動，並跳過連續相同的數字，避免同一個 `i` 產生重複結果。

## 複雜度

- 排序：`O(N log N)`
- 外層迴圈搭配雙指標：`O(N^2)`
- 總時間複雜度：`O(N^2)`
- 額外空間複雜度：`O(1)`，不計算回傳結果所需的空間
